# 🔌 USB Hub

A compact **4-Port USB 2.0 Hub** designed using **EasyEDA**, providing reliable USB connectivity through a single upstream USB connection. The project includes the complete schematic, PCB layout, and manufacturing files for PCB fabrication.

![PCB Preview](images/pcb.png)

---

## 📖 Overview

This project was created to design a compact and reliable USB hub PCB suitable for personal electronics projects and learning PCB design.

The PCB was designed in **EasyEDA** following USB 2.0 design guidelines, with proper routing, power distribution, and component placement.

---

## ✨ Features

- 🔹 4 USB 2.0 downstream ports
- 🔹 Single upstream USB connection
- 🔹 Compact PCB layout
- 🔹 EasyEDA schematic and PCB design
- 🔹 Gerber files ready for fabrication
- 🔹 Beginner-friendly hardware project

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/Ains0X1/USB-Hub.git
```

2. Open the EasyEDA project.

3. Review the schematic.

4. Export Gerber files if modifications are made.

5. Fabricate and assemble the PCB.
